# CA 2 MDP Armoured Warfare 1944-

This is my submission for CA 2 Adam Kavanagh 

The game is based of of the in class altered featuring tanks 
Currently the game includes a tutorial to get used to the control and the multiplayer game itself

Controls (Gameplay)
- Classic WASD movement for the tanks chassis (body) but are customizable 
- Arrow keys for turret rotation 
- Enter and Space are used to Fire the cannon (Short delay between firing)
